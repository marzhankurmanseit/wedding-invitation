## 🎵 Музыка («Жар-жар») қалай қосылады

Авторлық аудиожазбаны мен сізге орната алмадым (авторлық құқық). Ойнатқыш толық дайын — тек файлды қосу қалды:

1. «Жар-жар» әнінің **.mp3** файлын тауып алыңыз.
2. Оның атын **`music.mp3`** деп өзгертіңіз.
3. `index.html` жанына, **осы папкаға** салыңыз.

Болды! Қонақ сайтты ашып, бірінші рет басқан кезде әуен ақырын қосылады. Оң жақ төменгі бұрыштағы дөңгелек түймемен қосуға/өшіруге болады.

> Файл атауы міндетті түрде `music.mp3` болуы керек.

## Өзгерту керек болса

Барлық мәтін, түс, мәлімет `index.html` ішінде. Негізгі жерлер:

- Есімдер, күн, мекенжай — HTML ішіндегі сәйкес бөлімдерде
- Таймер күні — `new Date('2026-10-20T19:00:00+05:00')` жолында
- Telegram нөмірі — JavaScript ішіндегі `var PHONE = '77016756077'` жолында
- Түстер — `<style>` ішіндегі `:root` бөлімінде (`--accent` — негізгі алтын түс)
